Axios PR Reviewer

Paste any public GitHub PR link. Fresh PRs are fetched and reviewed live; previously reviewed PRs are served from cache.

  1. Paste any public GitHub PR URL into the input box above.
  2. Click Review — fresh PRs are fetched live from GitHub and cached for next time.
  3. Review tab — security risks, missing tests, breaking changes & verdict. Code Suggestions tab — actionable fixes with code blocks.
  4. Speed up reviews — use the findings as a checklist before approving or requesting changes.
